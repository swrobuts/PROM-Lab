Aufgaben, Ereignisse, Sequenzfluss Activities, events, sequence flow

Drei Symbole reichen für ein vollständiges Modell: ein Kreis für den Anfang, Rechtecke für das, was getan wird, ein dicker Kreis für das Ende, verbunden durch Pfeile. Was dieses Lab darüber hinaus lehrt, ist die Disziplin der Benennung. Sie entscheidet mehr über die Lesbarkeit eines Modells als jedes weitere Symbol. Three symbols suffice for a complete model: a circle for the beginning, rectangles for what is done, a thick circle for the end, connected by arrows. What this lab teaches beyond that is the discipline of naming. It decides more about the readability of a model than any further symbol.

Die AufgabeThe activity

AufgabeTask ein Schritt, den jemand oder etwas ausführta step someone or something performs
  • BedeutungMeaningEine Marke, die hier ankommt, wartet, bis die Tätigkeit erledigt ist, und läuft dann weiter.A token that arrives here waits until the work is done, then moves on.
  • KörnungGranularitySo grob wie möglich, so fein wie nötig: eine Aufgabe je Tätigkeit, nicht je Handgriff.As coarse as possible, as fine as necessary: one task per activity, not per hand movement.
  • FlüsseFlowsGenau ein eingehender und ein ausgehender Sequenzfluss. Mehrere Ausgänge sind Sache eines Gateways.Exactly one incoming and one outgoing sequence flow. Several exits are a gateway's business.
  • TypenTypesEin kleines Symbol oben links kennzeichnet optional, wer arbeitet: Mensch, System, Hand, Umschlag. Ein leeres Rechteck ist nie falsch.A small icon top left optionally marks who works: person, system, hand, envelope. An empty rectangle is never wrong.

Stolperfalle:Pitfall: „Kaffee brühen und Becher füllen“ ist keine Aufgabe, sondern zwei. Das Und im Namen ist das Warnsignal. “Brew coffee and fill cup” is not one task but two. The “and” in the name is the warning sign.

Start- und EndereignisStart and end event

Startereignis · EndereignisStart event · end event wo eine Instanz beginnt und wo sie endetwhere an instance begins and where it ends
  • StartStartDünner Kreis. Hier wird die Marke geboren. Der Name sagt, was eingetreten ist: „Kaffee bestellt“, „Patient aufgerufen“.Thin circle. The token is born here. The name says what has occurred: “coffee ordered”, “patient called”.
  • EndeEndDicker Kreis. Die Marke verschwindet. Der Name sagt, was das Ergebnis ist: „Kaffee ausgegeben“, „Proben versandbereit“.Thick circle. The token disappears. The name says what the result is: “coffee handed over”, “samples ready for dispatch”.
  • AnzahlCountGenau ein Start je Prozess (Ausnahmen später). Endereignisse dürfen mehrere sein, eines je unterscheidbarem Ergebnis.Exactly one start per process (exceptions later). End events may be several, one per distinguishable result.
  • FlüsseFlowsDer Start hat nur ausgehende, das Ende nur eingehende Sequenzflüsse.The start has only outgoing, the end only incoming sequence flows.

Stolperfalle:Pitfall: Ein Ereignis ist keine Tätigkeit. „Bestellung aufnehmen“ als Startereignis ist falsch; der Start ist „Bestellung eingegangen“, das Aufnehmen die erste Aufgabe. An event is not an activity. “Take order” as a start event is wrong; the start is “order received”, taking it is the first task.

Der SequenzflussThe sequence flow

SequenzflussSequence flow die Reihenfolge, in der die Marke läuftthe order in which the token runs
  • BedeutungMeaningErst das eine, dann das andere. Durchgezogene Linie, gefüllte Spitze.First one, then the other. Solid line, filled arrowhead.
  • RichtungDirectionVon links nach rechts. Ein Modell, das man von rechts nach links liest, ist eine Zumutung.Left to right. A model read right to left is an imposition.
  • GrenzeBoundaryEin Sequenzfluss bleibt immer innerhalb eines Pools (Lab 06).A sequence flow always stays inside one pool (lab 06).

Stolperfalle:Pitfall: Zwei Pfeile aus einer Aufgabe heraus bedeuten in BPMN, dass beide Pfade beschritten werden. Wer verzweigen will, braucht ein Gateway. Two arrows out of a task mean in BPMN that both paths are taken. If you want to branch, you need a gateway.

BenennungNaming

Die BPMN-Spezifikation schreibt keine Namen vor. Die Praxis hat sich auf zwei Konventionen geeinigt, die auch der Regelprüfer dieser Umgebung anmahnt: The BPMN specification prescribes no names. Practice has settled on two conventions, which the rule checker of this environment also reminds you of:

Warum das so streng istWhy it is this strict

Ein Modell wird zehnmal häufiger gelesen als geschrieben, meist von Personen ohne BPMN-Kenntnis. Das Verb sagt ihnen, was zu tun ist; das Partizip, was passiert ist. Ein Substantiv allein („Prüfung“) lässt offen, ob geprüft wird, geprüft wurde oder eine Prüfung eingeht. Und ein Werkzeug, das Aufgaben zu Arbeitsanweisungen macht, kann aus „Rechnung prüfen“ eine Anweisung ableiten, aus „Rechnungsprüfung“ nicht. A model is read ten times more often than written, mostly by people without BPMN knowledge. The verb tells them what to do; the participle what has happened. A noun alone (“check”) leaves open whether something is being checked, has been checked or a check is arriving. And a tool that turns tasks into work instructions can derive an instruction from “check invoice”, not from “invoice check”.

Beispiel: BlutentnahmeExample: blood sampling

Sobald ein Patient aufgerufen wird, prüft die medizinische Fachangestellte seine Identität, etikettiert die Röhrchen, entnimmt Blut, versorgt die Einstichstelle und verpackt die Proben für den Laborkurier. Fünf Tätigkeiten, keine Entscheidung, ein Ergebnis. So sieht das als Modell aus: As soon as a patient is called, the medical assistant checks their identity, labels the tubes, draws blood, dresses the puncture site and packs the samples for the lab courier. Five activities, no decision, one result. This is what it looks like as a model:

Von der Beschreibung zum Modell.From description to model. Unterstreichen Sie in der Beschreibung die Verben: prüfen, etikettieren, entnehmen, versorgen, verpacken. Jedes Verb mit seinem Objekt ist eine Aufgabe. Das Wort „sobald“ verrät den Auslöser, „für den Laborkurier“ das Ergebnis. Diese Lesetechnik trägt durch alle weiteren Labs, auch wenn Gateways und Ereignisse dazukommen. Underline the verbs in the description: check, label, draw, dress, pack. Every verb with its object is a task. The word “as soon as” reveals the trigger, “for the lab courier” the result. This reading technique carries through all further labs, even when gateways and events are added.

ÜbungenExercises

Fünf Übungen: zweimal lesen, einmal Fehler suchen, zweimal selbst modellieren. Der Editor zeichnet mit derselben Bibliothek wie bpmn.io; „Prüfen“ nennt Regelverstöße und vergleicht die Struktur mit der Aufgabe. Es gibt mehrere richtige Modelle. Five exercises: read twice, hunt errors once, model yourself twice. The editor draws with the same library as bpmn.io; “Check” names rule violations and compares the structure with the task. There is more than one correct model.

ZusammenfassungSummary

  • Ein vollständiges Modell hat ein Startereignis, Aufgaben und mindestens ein Endereignis, verbunden durch Sequenzflüsse von links nach rechts.A complete model has a start event, tasks and at least one end event, connected by sequence flows from left to right.
  • Eine Aufgabe enthält genau eine Tätigkeit und heißt Substantiv + Verb im Infinitiv.A task contains exactly one activity and is named verb + object.
  • Ein Ereignis ist ein eingetretener Zustand, kein Tun: Partizip statt Infinitiv.An event is a state that has occurred, not an action: participle instead of infinitive.
  • Die Verben der Prozessbeschreibung sind die Aufgaben, „sobald“ und „wenn“ sind die Ereignisse.The verbs of the process description are the tasks, “as soon as” and “when” are the events.
