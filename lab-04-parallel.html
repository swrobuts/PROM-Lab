Nebenläufigkeit: parallel und inklusiv Concurrency: parallel and inclusive

Nicht alles geschieht nacheinander. Beim Rüsten einer Maschine laufen drei Tätigkeiten unabhängig voneinander, in der Pizzeria wird gebacken, eingeschenkt und angerichtet, je nachdem, was bestellt ist. Dieses Lab führt das parallele und das inklusive Gateway ein und zeigt an Marken, warum ein Block mit demselben Gatewaytyp schließen muss, mit dem er geöffnet wurde. Not everything happens in sequence. When setting up a machine three activities run independently; in the pizzeria baking, pouring and preparing happen depending on what was ordered. This lab introduces the parallel and the inclusive gateway and shows with tokens why a block must close with the same gateway type it was opened with.

Das parallele GatewayThe parallel gateway

Werkzeug wechseln, Material bereitstellen, Programm laden: Drei Tätigkeiten, deren Reihenfolge keine Rolle spielt und die von drei Personen gleichzeitig erledigt werden können. Ein Modell, das sie hintereinander zeichnet, behauptet eine Reihenfolge, die es nicht gibt, und verschenkt Durchlaufzeit. Das parallele Gateway sagt: alle zugleich. Change the tool, provide material, load the program: three activities whose order does not matter and which three people can do at the same time. A model that draws them one after another claims an order that does not exist and wastes lead time. The parallel gateway says: all at once.

Paralleles Gateway (AND)Parallel gateway (AND) alle Pfade zugleichall paths at once
  • VerzweigungSplitDie Marke wird vervielfältigt: eine je ausgehendem Pfad. Keine Bedingungen, keine Frage.The token is multiplied: one per outgoing path. No conditions, no question.
  • ZusammenführungJoinWartet, bis auf jedem eingehenden Pfad eine Marke angekommen ist, und gibt genau eine weiter (Synchronisation).Waits until a token has arrived on every incoming path and passes on exactly one (synchronisation).
  • BeschriftungLabellingKeine. Ein paralleles Gateway stellt keine Frage.None. A parallel gateway asks no question.

Stolperfalle:Pitfall: Nebenläufig heißt nicht gleichzeitig ausgeführt, sondern in beliebiger Reihenfolge. Ob eine Person die drei Tätigkeiten nacheinander erledigt oder drei Personen parallel, entscheidet die Ressource, nicht das Modell. Concurrent does not mean executed simultaneously but in any order. Whether one person does the three activities in sequence or three people in parallel is decided by the resource, not the model.

Das inklusive GatewayThe inclusive gateway

Zwischen „genau einer“ und „alle“ liegt „einer oder mehrere“: Der Gast bestellt Pizza, Getränk oder Dessert in jeder Kombination. Mit XOR bräuchte man sieben Pfade für alle Kombinationen, mit AND würde jeder Gast alles bekommen. Das inklusive Gateway prüft jede Bedingung für sich und aktiviert jeden Pfad, dessen Bedingung zutrifft. Between “exactly one” and “all” lies “one or more”: the guest orders pizza, drink or dessert in any combination. With XOR you would need seven paths for all combinations, with AND every guest would get everything. The inclusive gateway checks every condition on its own and activates every path whose condition holds.

Inklusives Gateway (OR)Inclusive gateway (OR) ein oder mehrere Pfadeone or more paths
  • VerzweigungSplitJeder Pfad mit zutreffender Bedingung erhält eine Marke; mindestens einer muss zutreffen, sonst hilft ein Standardfluss.Every path with a true condition gets a token; at least one must hold, otherwise a default flow helps.
  • ZusammenführungJoinWartet nur auf die Marken, die tatsächlich unterwegs sind. Das macht die Zusammenführung anspruchsvoll für Werkzeuge, aber lesbar für Menschen.Waits only for the tokens actually on their way. That makes the join demanding for tools but readable for humans.
  • BeschriftungLabellingWie beim XOR: Frage am Gateway, Bedingung an jedem Pfad.As with XOR: question at the gateway, condition on every path.

Stolperfalle:Pitfall: Ein OR mit nur zwei sich ausschließenden Bedingungen („ja“ / „nein“) ist ein verkleidetes XOR. Nehmen Sie das XOR. An OR with only two mutually exclusive conditions (“yes” / “no”) is an XOR in disguise. Use the XOR.

Blöcke sauber schließenClosing blocks properly

Die wichtigste Regel dieses Labs: Was mit einem Gatewaytyp öffnet, schließt mit demselben Typ. Der Grund liegt im Verhalten der Marken. The most important rule of this lab: what opens with one gateway type closes with the same type. The reason lies in the behaviour of the tokens.

Öffnet mitOpens withSchließt mitCloses withWas passiertWhat happens
XORXOREine Marke hinein, eine hinaus. Richtig.One token in, one out. Correct.
ANDANDDrei Marken hinein, die Zusammenführung wartet auf alle drei, eine hinaus. Richtig.Three tokens in, the join waits for all three, one out. Correct.
XORANDEine Marke kommt an, die Zusammenführung wartet auf zwei weitere, die nie kommen. Deadlock.One token arrives, the join waits for two more that never come. Deadlock.
ANDXORDrei Marken kommen an, jede läuft einzeln weiter. Der Rest des Prozesses läuft dreimal.Three tokens arrive, each continues on its own. The rest of the process runs three times.
ORORSo viele Marken hinein wie Bedingungen zutrafen, die Zusammenführung wartet genau auf diese. Richtig.As many tokens in as conditions held, the join waits exactly for those. Correct.

Die Patientenaufnahme zeigt zwei Blöcke hintereinander: erst XOR (Versicherung), dann AND (Bett, Untersuchung, Armband). Vier Gateways, jedes mit genau einer Funktion. Patient admission shows two blocks one after another: first XOR (insurance), then AND (bed, examination, wristband). Four gateways, each with exactly one function.

ZusammenfassungSummary

  • AND vervielfältigt die Marke und wartet bei der Zusammenführung auf alle.AND multiplies the token and waits for all at the join.
  • OR aktiviert jeden Pfad mit zutreffender Bedingung und wartet genau auf diese.OR activates every path with a true condition and waits exactly for those.
  • Ein Block schließt mit dem Typ, mit dem er öffnet; sonst Deadlock oder Mehrfachausführung.A block closes with the type it opens with; otherwise deadlock or multiple execution.
  • Nebenläufigkeit im Modell heißt: beliebige Reihenfolge, nicht zwingend gleichzeitig.Concurrency in the model means any order, not necessarily simultaneous.
