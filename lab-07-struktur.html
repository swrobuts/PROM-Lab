Struktur: Teilprozesse, Daten, Schleifen Structure: subprocesses, data, loops

Reale Prozesse haben dreißig, sechzig, hundert Schritte. Damit ein Modell lesbar bleibt, gliedert BPMN in Teilprozesse, lagert Wiederverwendetes in Aufrufaktivitäten aus, zeigt die Daten, die Aufgaben lesen und schreiben, und markiert Wiederholungen an der Aufgabe statt sie auszuzeichnen. Das Lab führt diese Mittel an einer Instandhaltung, einer Losprüfung und einer Visite ein. Real processes have thirty, sixty, a hundred steps. To keep a model readable, BPMN structures into subprocesses, moves reused parts into call activities, shows the data that tasks read and write, and marks repetitions on the task instead of drawing them out. The lab introduces these means with a maintenance job, a lot inspection and a ward round.

Teilprozesse und AufrufaktivitätenSubprocesses and call activities

Ein Modell mit sechzig Aufgaben auf einer Ebene liest niemand. BPMN gliedert hierarchisch: Ein Teilprozess fasst zusammengehörige Schritte in einem Rahmen zusammen, der von außen wie eine Aufgabe wirkt und innen einen eigenen Ablauf mit Start und Ende hat. Aufgeklappt zeigt er seinen Inhalt, zugeklappt nur ein Plus. Die Aufrufaktivität geht einen Schritt weiter: Sie verweist auf einen eigenständigen Prozess, der einmal modelliert und an vielen Stellen aufgerufen wird. Nobody reads a model with sixty tasks on one level. BPMN structures hierarchically: a subprocess groups related steps in a frame that acts like a task from the outside and has its own flow with start and end inside. Expanded, it shows its content; collapsed, only a plus. The call activity goes one step further: it references an independent process that is modelled once and called in many places.

Teilprozess · AufrufaktivitätSubprocess · call activity Hierarchie und Wiederverwendunghierarchy and reuse
  • EingebettetEmbeddedGehört nur zu seinem Elternprozess. Kein Sequenzfluss kreuzt den Rahmen; innen eigener Start, eigenes Ende.Belongs only to its parent process. No sequence flow crosses the frame; own start and end inside.
  • AufrufaktivitätCall activityDicker Rahmen. Ruft einen globalen Prozess auf, der ein eigenes Diagramm hat und von mehreren Prozessen benutzt wird.Thick border. Calls a global process that has its own diagram and is used by several processes.
  • RandereignisseBoundary eventsAuch an einen Teilprozess lassen sich Ereignisse anheften; ein Fehler-Endereignis innen wird dann außen gefangen.Events can be attached to a subprocess too; an error end event inside is then caught outside.

Stolperfalle:Pitfall: Ein Teilprozess mit nur einer Aufgabe darin ist keine Gliederung, sondern Dekoration. Gliedern Sie, wo drei bis zehn Schritte einen Namen haben. A subprocess with only one task inside is not structure but decoration. Structure where three to ten steps have a name.

Datenobjekte und DatenspeicherData objects and data stores

Prozesse verarbeiten Informationen: Formulare, Datensätze, Berichte. BPMN zeigt sie als Datenobjekte (das Blatt mit Eselsohr) und verbindet sie gepunktet mit den Aufgaben, die sie lesen oder erzeugen. Ein Datenobjekt gehört zu einer Instanz: diese eine Störmeldung. Ein Datenspeicher (die Tonne) überdauert alle Instanzen: das Instandhaltungssystem mit allen Aufträgen. Processes handle information: forms, records, reports. BPMN shows them as data objects (the sheet with a dog ear) and links them with dotted lines to the tasks that read or produce them. A data object belongs to one instance: this one fault report. A data store (the barrel) outlives all instances: the maintenance system with all orders.

Datenobjekt · DatenspeicherData object · data store was eine Aufgabe braucht und erzeugtwhat a task needs and produces
  • DatenobjektData objectInstanzdatum. Der Pfeil der Assoziation zeigt, ob die Aufgabe liest (Pfeil zur Aufgabe) oder schreibt (Pfeil zum Objekt).Instance data. The arrow of the association shows whether the task reads (arrow to the task) or writes (arrow to the object).
  • DatenspeicherData storeBestandsdatum: Datenbank, ERP, Aktenschrank. Bleibt, wenn die Instanz vorbei ist.Persistent data: database, ERP, filing cabinet. Remains when the instance is over.
  • SparsamkeitEconomyNur die Daten zeigen, die etwas erklären: das Formular, das abgetippt wird; das System, aus dem gelesen wird.Show only the data that explain something: the form that is retyped; the system that is read from.

Stolperfalle:Pitfall: Dasselbe Datenobjekt zweimal, einmal „Formular (Papier)“, einmal „Bestellung (Datensatz)“: Das ist kein Modellierungsfehler, sondern ein Befund. Es heißt Medienbruch (Lab 08). The same data object twice, once “form (paper)”, once “order (record)”: that is not a modelling error but a finding. It is called a media break (lab 08).

Schleifen und MehrfachinstanzenLoops and multi-instances

Manche Aufgaben wiederholen sich: Nacharbeiten, bis die Prüfung besteht. Und manche laufen je Element einer Liste: jedes Teil der Stichprobe prüfen, jeden Patienten visitieren. Statt Rückschleifen über Gateways zu zeichnen, trägt die Aufgabe einen Marker. Some tasks repeat: rework until the inspection passes. And some run per element of a list: check every part of the sample, visit every patient. Instead of drawing loops via gateways, the task carries a marker.

Schleife · MehrfachinstanzLoop · multi-instance Wiederholung als Markierungrepetition as a marker
  • SchleifeLoopPfeil im Kreis: Die Aufgabe wiederholt sich, bis eine Bedingung erfüllt ist. Die Bedingung steht in der Aufgabe, nicht am Pfeil.Circular arrow: the task repeats until a condition is met. The condition lives in the task, not on an arrow.
  • ParallelParallelDrei senkrechte Striche: eine Instanz je Element, alle zugleich. Die Anzahl steht erst zur Laufzeit fest.Three vertical bars: one instance per element, all at once. The number is only known at runtime.
  • SequenziellSequentialDrei waagerechte Striche: eine Instanz je Element, nacheinander.Three horizontal bars: one instance per element, one after another.

Stolperfalle:Pitfall: Ein Marker versteckt die Wiederholung im Element. Wiederholen sich mehrere Schritte, ist die sichtbare Rückschleife über ein Gateway lesbarer. A marker hides the repetition in the element. If several steps repeat, the visible loop via a gateway reads better.

ÜbungenExercises

Fünf Übungen: drei Modelle erkunden, ein Quiz, ein Modell mit allen drei Strukturmitteln. Im Editor setzen Sie Marker und Teilprozess über den Schraubenschlüssel einer Aufgabe; Daten ziehen Sie aus der Palette.Five exercises: explore three models, a quiz, one model with all three structural means. In the editor, set markers and subprocess via a task's wrench; drag data from the palette.

ZusammenfassungSummary

  • Teilprozesse gliedern, Aufrufaktivitäten verwenden wieder; kein Sequenzfluss kreuzt einen Rahmen.Subprocesses structure, call activities reuse; no sequence flow crosses a frame.
  • Datenobjekte gehören zur Instanz, Datenspeicher überdauern sie.Data objects belong to the instance, data stores outlive it.
  • Schleifen- und Mehrfachinstanzmarker ersetzen Rückschleifen und Gateways mit unbekannter Pfadzahl.Loop and multi-instance markers replace loops and gateways with an unknown number of paths.
  • Zeigen Sie nur die Daten, die etwas erklären.Show only the data that explain something.
