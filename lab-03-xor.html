Entscheidungen: das exklusive Gateway Decisions: the exclusive gateway

Kaum ein Prozess läuft für jede Instanz gleich. Ob die Räder eingelagert werden, wie dringend ein Patient ist, ob eine Rücksendung vollständig ist: An solchen Stellen verzweigt der Ablauf. Dieses Lab führt das exklusive Gateway ein, die Beschriftung seiner Pfade, den Standardfluss, die Zusammenführung und die Rückschleife. Hardly any process runs the same for every instance. Whether the wheels are stored, how urgent a patient is, whether a return is complete: at such points the flow branches. This lab introduces the exclusive gateway, the labelling of its paths, the default flow, the merge and the loop.

Das exklusive GatewayThe exclusive gateway

Bisher lief jede Instanz denselben Weg. Sobald sich Instanzen unterscheiden, etwa weil ein Kunde die Einlagerung gebucht hat und ein anderer nicht, braucht das Modell eine Weiche. Das exklusive Gateway ist die häufigste: Genau ein Pfad wird gewählt. So far every instance ran the same way. As soon as instances differ, for instance because one customer booked storage and another did not, the model needs a switch. The exclusive gateway is the most common one: exactly one path is chosen.

Exklusives Gateway (XOR)Exclusive gateway (XOR) genau ein Pfad von mehrerenexactly one of several paths
  • BedeutungMeaningDie Marke nimmt genau einen ausgehenden Pfad: den ersten, dessen Bedingung zutrifft.The token takes exactly one outgoing path: the first whose condition holds.
  • BeschriftungLabellingDas Gateway trägt die Frage („Räder einlagern?“), jeder Pfad die Antwort („ja“, „nein“).The gateway carries the question, every path the answer.
  • StandardflussDefault flowEin Pfad darf statt einer Bedingung einen Schrägstrich tragen: Er gilt, wenn nichts anderes zutrifft.One path may carry a slash instead of a condition: it applies if nothing else holds.
  • MarkierungMarkerDas X im Rhombus ist optional; ein leerer Rhombus bedeutet dasselbe. Diese Umgebung zeigt das X.The X in the diamond is optional; an empty diamond means the same. This environment shows the X.

Stolperfalle:Pitfall: Ein Gateway entscheidet nicht, es verteilt. Wenn zum Entscheiden gearbeitet werden muss („Bonität prüfen“), steht diese Arbeit als Aufgabe vor dem Gateway. A gateway does not decide, it routes. If work is needed to decide (“check credit”), that work stands as a task before the gateway.

Bedingungen und StandardflussConditions and default flow

Die Bedingungen an den Pfaden eines exklusiven Gateways sollen zwei Eigenschaften haben: vollständig (jede Marke findet einen Weg) und überschneidungsfrei (nie zwei zugleich). Bei „ja / nein“ ist das offensichtlich. Bei „rot / gelb / grün“ in der Triage muss man hinsehen: Was passiert mit einem Patienten, dessen Einstufung noch fehlt? Der Standardfluss fängt diesen Fall auf, ohne dass man ihn ausformulieren müsste. The conditions on the paths of an exclusive gateway should have two properties: complete (every token finds a way) and disjoint (never two at once). With “yes / no” that is obvious. With “red / yellow / green” in triage you have to look: what happens to a patient whose classification is still missing? The default flow catches this case without spelling it out.

Ohne Bedingung ist es kein Modell.Without a condition it is not a model. Ein XOR-Pfad ohne Beschriftung ist der häufigste Fehler in Abgaben. Er lässt offen, wann der Pfad genommen wird, und macht das Modell für Simulation und Ausführung unbrauchbar. Regel R03 des Prüfers meldet ihn als Fehler, nicht als Warnung. An XOR path without a label is the most frequent error in submissions. It leaves open when the path is taken and makes the model useless for simulation and execution. Rule R03 of the checker reports it as an error, not a warning.

ZusammenführenMerging

Was verzweigt, wird meist wieder zusammengeführt: Nach der Einlagerung oder dem Kofferraum werden in beiden Fällen die Saisonräder montiert. Dafür steht ein zweites exklusives Gateway mit zwei eingehenden und einem ausgehenden Pfad. Es wartet auf nichts; jede ankommende Marke läuft sofort weiter. Die BPMN-Spezifikation erlaubt auch, zwei Pfeile direkt in die nächste Aufgabe laufen zu lassen. Die Konvention dieser Umgebung verlangt trotzdem das Gateway: Ein Leser sieht dann auf einen Blick, wo ein Block endet, und ein Block, der mit XOR öffnet, schließt mit XOR. What branches is usually merged again: after storage or the boot, in both cases the seasonal wheels are mounted. A second exclusive gateway with two incoming and one outgoing path stands for that. It waits for nothing; every arriving token continues at once. The BPMN specification also allows two arrows to run directly into the next task. The convention of this environment still requires the gateway: a reader then sees at a glance where a block ends, and a block that opens with XOR closes with XOR.

Ein Gateway, eine FunktionOne gateway, one function

Ein Gateway verzweigt oder führt zusammen. Ein Gateway mit zwei Eingängen und drei Ausgängen ist erlaubt, aber schwer zu lesen; der Prüfer warnt (R04). Zeichnen Sie zwei. A gateway splits or merges. A gateway with two entries and three exits is allowed but hard to read; the checker warns (R04). Draw two.

RückschleifenLoops

Ein Pfad darf auch zurückführen: Ist die Rücksendung unvollständig, werden Teile nachgefordert, und die Erfassung beginnt von vorn. Die Schleife führt zu einer Aufgabe zurück, nie zum Startereignis; das hat keinen eingehenden Fluss. Und sie braucht einen Ausweg: eine Bedingung, unter der der Prozess weiterläuft, sonst kreist die Marke ewig. A path may also lead back: if the return is incomplete, parts are requested and recording starts over. The loop leads back to a task, never to the start event; that has no incoming flow. And it needs a way out: a condition under which the process continues, otherwise the token circles forever.

Lesetechnik.Reading technique. In der Beschreibung verraten „wenn“, „falls“, „sonst“ und „andernfalls“ ein XOR-Gateway, „von vorn“ und „erneut“ eine Rückschleife, „in beiden Fällen“ eine Zusammenführung. In the description, “if”, “in case”, “otherwise” reveal an XOR gateway, “from the start” and “again” a loop, “in both cases” a merge.

ZusammenfassungSummary

  • Das exklusive Gateway lässt genau eine Marke auf genau einem Pfad weiter; die Bedingung entscheidet.The exclusive gateway lets exactly one token continue on exactly one path; the condition decides.
  • Das Gateway trägt die Frage, jeder Pfad die Antwort; ein Pfad darf Standardfluss sein.The gateway carries the question, every path the answer; one path may be the default flow.
  • Was mit XOR öffnet, schließt mit XOR; die Zusammenführung wartet nicht.What opens with XOR closes with XOR; the merge does not wait.
  • Rückschleifen führen zu einer Aufgabe zurück und brauchen einen Ausweg.Loops lead back to a task and need a way out.
